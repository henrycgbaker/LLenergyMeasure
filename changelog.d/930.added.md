Two opt-in optional-dependency extras: `[optimize]` (`pip install 'llenergymeasure[optimize]'`) pulling `scipy>=1.15`, and `[screen]` (`pip install 'llenergymeasure[screen]'`) pulling `[optimize]` plus `SALib>=1.5.2` for Morris/Sobol sensitivity screening. Core dependencies are unchanged, so a plain `pip install llenergymeasure` installs neither. Note that `[screen]` requires numpy 2 (SALib's floor) where the core allows `numpy>=1.24`. Separately, built wheels now declare their licence: `METADATA` carries `License-Expression: MIT` and ships the `LICENSE` file, which it previously omitted.
