**Breaking (runner vocabulary):** the runner mode is renamed `local`/`docker` -> `process`/`container` (image shorthand `docker:<image>` -> `container:<image>`) and the no-spec `source` sentinel `local` -> `implicit`, naming the packaging axis symmetrically. Clean break, not an alias: every entry point that parses a user-supplied runner value (study YAML `runners:`, `LLEM_RUNNER_<ENGINE>`, user config) rejects the old values with a migration error, and `RunnerProvenance.mode` is now a closed `Literal`, so a pre-v0.7 bundle carrying the old mode fails validation loudly on read. Update any pinned `runners:` values to the new vocabulary.
