Runner auto-detection is now container-self-aware. When llenergymeasure runs inside a container without a usable Docker socket, auto-detection selects process mode instead of attempting docker-in-docker (previously a stray `docker` CLI on PATH would make it try); with a mounted socket it keeps container mode (docker-outside-of-docker siblings via the host daemon). Multi-engine elevation gained the same awareness, failing with an actionable error instead of attempting DinD. Explicit runner pins (env var, study YAML, user config) are unchanged.
