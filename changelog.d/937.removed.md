Five user-config fields that were parsed but never read by anything are deleted, along with their environment-variable feeders. This is a hard break: a `~/.config/llenergymeasure/config.yaml` still carrying one of them now fails loudly at load, and the error names the removed field and the mechanism that covers the need instead.

- `output.model_cache_dir` - model caching already follows the standard HuggingFace cache environment variables (`HF_HOME` etc.), and container runs mount the cache via `LLEM_DOCKER_HF_CACHE`.
- `measurement.carbon_intensity_gco2_kwh` and `measurement.datacenter_pue` (with env vars `LLEM_CARBON_INTENSITY` and `LLEM_DATACENTER_PUE`) - CO2 estimation is the CodeCarbon sampler's job, which sources grid intensity and PUE itself; these values were never wired into any calculation.
- `ui.log_level` - logging is controlled by the `-v` flag or the `LLEM_LOG_LEVEL` env var; this field was never consulted.
- `ui.prompt` (with env var `LLEM_NO_PROMPT`) - the tool has no interactive prompts to disable.

`measurement.energy_sampler` and `ui.progress_mode` are unchanged.
