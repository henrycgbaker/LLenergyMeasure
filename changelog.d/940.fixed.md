GPU CI no longer claims every device on the runner. The `transformers` job's two test containers asked Docker for `--gpus all`, and on a shared GPU host the allocation wrapper charges a whole-host request against the account's entire GPU quota, so a CI run starved any measurement work running beside it for the length of the job and repeatedly blocked long-running studies. Both containers now request a single device (`--gpus 1`), which is all the job ever needed: it exercises one engine in one process. The `gpu-ci` make target, a hand-run mirror of the same job, carried the same request and is fixed with it. The request is deliberately a bare count rather than a device index, because the host's allocation wrapper rewrites a count into whichever device it has actually allocated.
