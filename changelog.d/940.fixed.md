GPU CI no longer claims every device on the runner. The `transformers` job's two test containers asked Docker for `--gpus all`, and on a shared GPU host a whole-host request is charged against the account's whole GPU quota, so a CI run starved any measurement work running beside it for the length of the job and repeatedly blocked long-running studies. Both containers now request a single device (`--gpus 1`), which is all the job ever needed: it exercises one engine in one process. The `gpu-ci` make target, a hand-run mirror of the same job, carried the same request and is fixed with it. The request is deliberately a bare count rather than a device index, because a count leaves the choice of device to the host, which is the only party that knows which devices are free.
